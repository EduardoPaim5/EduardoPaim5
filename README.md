## Featured projects

### [PulseAPI](https://github.com/EduardoPaim5/pulseapi)

Uptime monitoring service built with Java 17 and Spring Boot. It includes REST APIs, JWT authentication, RBAC, background checks, PostgreSQL, Flyway, Docker, automated tests and availability metrics.

### GraphCognitio — [Backend](https://github.com/GraphCognitio/graphcognitio) · [Frontend](https://github.com/GraphCognitio/graphcognitio-web)

Collaborative graph-oriented social platform built with Java/Spring Boot, React and TypeScript. The project includes JWT authentication, RBAC, auditing, cursor-based feeds, full-text search, caching, rate limiting, idempotency and an interactive graph interface.

### [BeTalent Payments API](https://github.com/EduardoPaim5/betalent-payments-api)

Laravel REST API for multi-gateway payments, with priority-based fallback, refunds, role-based authorization, idempotency, automated tests, HTTP smoke tests and a fully containerized Docker environment.

### [PulseAPI Web](https://github.com/EduardoPaim5/pulseapi-web)

React and TypeScript dashboard for PulseAPI, with authentication, monitor management, availability metrics, alerts, TanStack Query, Tailwind CSS and a deployed demo.

### [Performance Reproducibility](https://github.com/EduardoPaim5/performance-reproducibility)

Reproducible performance experiment comparing Nginx deployments across native Linux, Docker, Docker Swarm and AWS EC2 using k6, Prometheus and Grafana.

### [PVault](https://github.com/EduardoPaim5/pvault)

Experimental local-first password vault for Linux written in C11. It explores authenticated encryption with Argon2id, XChaCha20-Poly1305, libsodium, atomic writes and a documented threat model.

> PVault is pre-alpha software and has not received an independent security audit. It should not be used to store real credentials.
